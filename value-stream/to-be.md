# Value Stream TO-BE — Sprint 0

Propongan el flujo objetivo, indiquen qué automatizarían primero y justifiquen la decisión con evidencia del AS-IS.

Flujo objetivo
1. Crear o consultar el documento READ ME del proyecto.
2. Verificar que todos los integrantes tengan las herramientas necesarias previamente descargadas y funcionales (IDE, GitHub, Visual, etc.).
3. Verificar que todos los integrantes tengan las extensiones o librerías necesarias.
4. Verificar que el proyecto funcione localmente para cada integrante.
5. Crear y asignar una rama según sea necesario.

Cómo comprobar la mejora: Se obtiene un inicio y configuración del proyecto más rápido y sin inconvenientes.

Justificación de la decisión: En el AS-IS surgieron fricciones al no tener las herramientas necesarias instaladas en el dispositivo.
